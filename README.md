Midnight — A Coffee Lover’s Website

Welcome to Midnight, a beautifully designed coffee website where users can explore premium brews, browse elegant sections, and enjoy a smooth, dark-themed interface.

Live Site: https://midnight-com.vercel.app/


Overview

Midnight is a fictional coffee brand site built to showcase modern frontend development skills. It combines clean layout, smooth animations, and mobile responsiveness to deliver a luxurious browsing experience. The entire project focuses on visual polish, interactivity, and seamless user flow.

Tech Stack

HTML5 — For semantic structure and page layout  
Tailwind CSS — For fast, utility-first styling and responsive design  
JavaScript (ES6) — For dynamic behavior and user interaction  
React.js — For building modular, reusable components  

Features

- Fully responsive design with mobile-first focus  
- Dark-themed layout for a premium look and feel  
- GSAP-powered animations for smooth interactions  
- Product highlights for coffee blends and lifestyle appeal
